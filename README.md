Cochera is a study guide generator. The AI breaksdown the subject into week by week topics. Each topic will be a unique sub topic of the subject that the user wants to learn about.

The AI will fetch reliable and quality articles and videos for the user to learn about each sub topic.

The user inputs a subject

The AI asks questions

The AI creates a week by week topic list

The user edits the topic list

The AI find materials for each week

The website tracks daily learning
